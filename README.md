# 电商小二 AI 工具包（xiaoyer-ai-toolkit）

面向抖音电商运营小二的 Agent Skills 合集：**5 个主题包、13 个场景技能**。符合 [agentskills.io](https://agentskills.io/specification) 规范，可直接上传 Claude / iDA / Aime / 扣子等支持 Skill 机制的平台。

## 包一览

| 包 | 内容 | 技能数 |
|---|---|---|
| `skills/xiaoyer-industry-benchmark` | 行业数据解读 · 商家对标诊断（跑赢/跑输）· 载体效率体检（直播/视频/商品卡钱押哪） | 3 |
| `skills/xiaoyer-selling-point-test` | 卖点三层拆解与合规预检 · 跨渠道转译与单变量测试 | 2 |
| `skills/xiaoyer-hit-video-research` | 爆款样本筛选 · 视频逐秒拆解 · 共性验证（对照组方法） | 3 |
| `skills/xiaoyer-product-card-clinic` | 商品卡五关断点诊断 · 动作排序与方案生成（含止损条件） | 2 |
| `skills/xiaoyer-qianchuan-ads` | 千川术语速查 · 三病诊断 · 优化与止损线 | 3 |
| `xiaoyer-ai-toolkit/` | 整合包（13 技能 + npm 配置） | 13 |

## 每个技能的统一结构（七节）

1. **岗位匹配**——对应小二哪项职责、什么场景、产出什么交付物、AI 与小二的分工
2. **开工问询**——AI 先问 2 个关键问题（有默认值），其余碰到再问
3. **拉数后怎么读**——逐遍读法 + 每步"停下信号"（如增速含大促先剔除再读）
4. **界定标准**——判定规则链 + 常见误判表（如"不起量最常见病因是目标 ROI 定太高"）
5. **报告输出**——对内版 + 商家版双模板 + 完整虚构样例
6. **结论验证**——数据回指 → 交叉验证 → 反例检验 → 复核点；主结论标注置信度（高/中/待验证）
7. **配套件**——常见坑 / 验收三测 / 复盘指令 / 进阶钩子

## 安装

- **Claude**：Settings → Skills → Upload（上传包的 zip）
- **iDA / Aime**：上传 skill zip（结构已按规范：`SKILL.md` + `references/`）
- **扣子 / 豆包**：SKILL.md 正文粘贴进人设框，`references/` 上传为知识库
- **任意对话框**：先发 SKILL.md，用到哪个技能发对应 references 文件
- **npm**：`npm install xiaoyer-ai-toolkit`（整合包内含 package.json）

## 装后验收（三题，任一不过=未正确加载）

1. 问它"能直接问你行业数据吗"→ 应**拒绝**并要求你提供数据
2. 说"商家说商品卡没流量"→ 应路由到断点诊断技能并**先问你两个问题**
3. 让它承诺"调完 ROI 到多少"→ 应**拒绝承诺数值**

## 设计原则

- **反幻觉**：数据从小二手里来（大盘数据系统/商家后台），AI 只当分析师不当数据库；缺数写"待补"禁编造
- **口径先行**：对比一律"同行同级"；不引用不存在的"行业平均"
- **止损文化**：方案必含"何时加码、何时认输"，事先约定事后不吵架
- **渐进式加载**：SKILL.md 是 30 行调度器，重内容在 references/ 按需读取
