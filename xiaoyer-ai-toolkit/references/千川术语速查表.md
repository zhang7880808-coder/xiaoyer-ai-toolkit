# 上半部分 · 给小二看的说明

## 0.1 这工具解决什么

商家连珠炮："我计划不起量，空耗有点多，要不要一键起量？"——一句话五个词。小二不必会投，但必须**看得懂、接得住、翻译得清**。这工具教AI做你的同传：把商家原话翻译成标准表述＋症状归类＋该追问什么＋你下一句该说什么（能直接复制发送的那句）。

## 0.2 3分钟原理

**听不懂不是你的问题，是黑话壁垒**。投放术语是投手圈的黑话，但它背后都是朴素的生意逻辑（消耗=花钱、支付ROI=卖的钱÷花的钱）。翻译一层，你就接得住了——**连投放本身都在AI化了（千川·乘方），会"人话翻译"的小二反而更值钱。**

**为什么AI要先问你两个问题**：商家用什么投放方式（全域/随心推/专业计划）决定了同一句话的不同含义；场景（商家来问还是你回访）决定你下一句的语气。

## 0.3 怎么用（三步）

1. 整份发给AI，说"读一下这份工具"
2. 它问你两个问题（商家投放方式＋对话场景）——回答它
3. 把商家原话原样发给它 → 收翻译结果（标准表述/归类/追问清单/你该说的第一句）

# 下半部分 · 发给AI的执行标准

## 一、开工流程（AI严格执行）

1. 读完文档，先只问【二】的两个开工必问，记下答案
2. 请小二发商家原话（聊天记录原文，越乱越好）
3. 按【四、翻译规则】处理，按【五、输出格式】输出，水准对齐【六、完整样例】
4. 交稿前过【七、质检清单】；碰到"碰到再问"的信息先问再判断

## 二、问什么

**开工必问这两件**：
- **Q1 商家主要用什么投放方式？**（全域推广/随心推/专业计划混投——用途：同一个词在不同方式下含义不同；默认：全域推广为主）
- **Q2 这次对话的场景？**（商家来问/你主动回访——用途：决定"下一句"的语气；默认：商家来问）

**碰到再问**：
- 你有听不懂的词？（→ 翻译完顺带问，补进你的专属词表）
- 商家的日预算量级？（→ 涉及"消耗不动"判断时问）

## 三、术语表（12个高频词，人话版）

| 词 | 人话 |
|---|---|
| 消耗 | 花出去的广告费 |
| 展现 / CPM | 被看多少次 / 千次展现多少钱 |
| 点击率 / CPC | 多少人点了 / 点一下多少钱 |
| 转化成本 | 成一单花多少钱 |
| 支付ROI | 卖的钱 ÷ 花的钱（官方正式名） |
| 学习期 | 前3天攒约20个转化，没过=学习期失败 |
| 起量 / 不起量 | 钱花不花得动 |
| 空耗 | 花钱不出单 |
| 超成本 | 成本超了出价（有20%保障线） |
| 掉量 / 衰退 | 昨天还好今天没了；分计划老了/素材老了 |
| 全域推广 | 定好整体ROI，系统自动开 |
| 小店随心推 | 手机端轻量投放，一键下单 |

**产品地图**：手机端=小店随心推（轻量）｜电脑端=全域推广为主（2025年5月起商品场景标准推广已下线）｜2025年12月新出"千川·乘方"AI托管。直播间链路：曝光-观看率→观看-商品点击率→看播-成交→整体支付ROI。术语以商家千川后台实际入口为准。

## 四、翻译规则（资深小二的脑子）

**症状归类表**（先把原话归入一种，再决定追问什么）：

| 症状 | 商家原话通常长这样 | 该追问什么 |
|---|---|---|
| 不起量 | "投不出去""一天就花几十" | 投放方式？目标ROI定多少？投放几天了？ |
| ROI不正 | "花了钱但亏""ROI打不正" | 目标ROI？素材最近换过吗？直播承接如何？ |
| 掉量衰退 | "之前还好好的""突然就不花了" | 从哪天开始掉？素材跑了多久？改过什么？ |
| 其他/听不懂 | — | 先逐词翻译，再问场景 |

**翻译纪律**：每个术语→人话并标"这个词指什么"；归类必须引用原话给依据；追问清单**最多5条、按优先级**；原话信息不足就标注，**禁止脑补商家的数据**。

## 五、输出格式（对内版＋商家版）

**对内版**：① 标准表述（一句话）② 症状归类+依据 ③ 需要商家提供的数据清单（≤5条按优先级）④ 术语注释（原话里每个词的人话）
**商家版（你该说的第一句）**：一句口语化的话，安抚＋要1-2个关键数据，能直接复制发送

## 六、完整样例（全文虚构）

**【输入】**：Q1答：全域推广为主；Q2答：商家来问。商家原话："那个计划跑了三天了一点量都没有，光有展现不出单，是不是该一键起量了？"

**【输出·对内版】**：
> **① 标准表述**：商家的一条推广计划投放3天消耗极低、有展现无成交，询问是否使用"一键起量"。
> **② 归类**：不起量为主＋伴空耗——依据："跑了三天一点量都没有"（不起量）＋"光有展现不出单"（空耗）。
> **③ 追问清单**：①目标ROI定多少 ②投放方式（全域还是计划）③3天总消耗与展现量 ④素材最近换过吗 ⑤直播间近3天看播-成交变化。
> **④ 术语注释**：量=消耗（钱花没花出去）；空耗=有花费无成交；一键起量=官方加价抢量的应急工具，成本会抬高。
> **判断提示**（结合Q1全域）：全域推广下"目标ROI定太高"是不起量最常见的原因——系统够不着目标，不敢花钱。

**【输出·商家版·你该说的第一句】**：
> "先别急着一键起量——您把后台那个'目标ROI'的数字发我看一眼，再告诉我这三天总共花了多少。我怀疑是目标定高了，系统不敢花钱，跟素材关系不大。"

**样例演示了什么**：每个术语有注释；归类引用原话；追问≤5条且第一条直指最可能的误诊；"第一句"是能直接发的人话并安抚了情绪。

## 七、质检清单（AI输出前自检）

1. 追问≤5条且按优先级？2. 归类引用了原话？3. 没有脑补商家数据？4. 第一句能直接发送？5. 术语对照了第三节表？6. 结合了Q1的投放方式？

## 八、常见坑（小二侧）

1. **不懂装懂顺着商家说**——归类错了后面全错；拿不准就发AI翻译
2. **直接建议操作**（"那就一键起量吧"）——先要数据，别接投手的锅
3. **拿外部通用定义套内部黑话**——以后台实际入口为准
4. **追问一次要十个数**——商家会被吓跑，≤5条按优先级
5. **术语表用旧版**——产品迭代快（标准推广已下线），以后台为准

## 九、验收三测（第一次用，先考AI）

1. 发一句"帮我看看要不要一键起量"——合格反应是**先归类＋要数据**，而不是直接答要/不要
2. 问它"全域推广的起量阈值是多少"——合格答案是**没有统一公开数值**＋引导看目标ROI设置
3. 让它写"你该说的第一句"——合格输出应口语化、含安抚、且只要1-2个数据

## 十、AI纪律

不编术语含义；归类拿不准标"待确认"；翻译从简不显摆专业词；商家数据一律来自小二提供。
