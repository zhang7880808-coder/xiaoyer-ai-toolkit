# 上半部分 · 给小二看的说明

## 0.1 这工具解决什么

看完爆款，人人都说"钩子好、节奏快"——这些是**感觉**，会错、没法验证、也没法复制。这工具分两种模式：

- **模式A（AI能读视频/抽帧时，优先）**：AI 逐段读视频、自动填三行记录初稿（事实列=实际看到的帧内容，看不清就写"待确认"），**你只校对三个关键字段**（卖点首现秒数/价格出现时机/信任证明方式）
- **模式B（AI读不了视频时）**：视频你来看、按四段时间轴填三行记录，AI 只做校准（专抓"把感受写成事实、把猜测写成结论"）

两模式共同红线：**AI 不得虚构未实际看到的画面**；带货数据永远由你提供（页面抓不到写"待补"）。拆完的结论，每条都能指回"第几秒的什么画面"。

## 0.2 3分钟原理

**为什么三行分开记**：一条视频看完，你脑子里"发生了什么（事实）/我觉得它在干嘛（解释）/我猜会有什么效果（假设）"是搅在一起的。混着记的后果：猜测被当成规律传给商家，一验证就翻车。三行分立=把"我觉得"拆成可验证的零件——**感觉不可复制，证据可复制。**

**为什么AI不碰视频**：AI没看过这条视频，让它"分析这条爆款"它只会一本正经地编。所以纪律：画面你来记，框架和校准它来管。

## 0.3 怎么用（三步）

1. 整份发给AI，说"读一下这份工具"
2. 它问你两个问题（拆什么类型/重点挑哪种毛病）——回答它
3. 你按第三节表拆完视频，把记录发给AI → 收校准报告

# 下半部分 · 发给AI的执行标准

## 一、开工流程（AI严格执行）

1. 读完文档，先只问【二】的两个开工必问，记下答案
2. 请小二发【三、记录表】；记录太薄（只有感受词）先退回重记，不开工
3. 按【四、校准规则】校准，按【五、报告格式】输出，水准对齐【六、完整样例】
4. 交稿前过【七、质检清单】；碰到"碰到再问"的信息先问再判断

## 二、问什么

**开工必问这两件**：
- **Q1 这次拆的视频什么类型、什么目的？**（带货复盘/对标学习/找出路——用途：校准侧重点不同；必须答）
- **Q2 你希望AI重点挑哪种毛病？**（用途：校准优先级；默认：把感受当事实、把猜测当结论）

**碰到再问**：
- 记录表想加列吗？（BGM变化/贴纸时机——开工前顺带问）
- 这条视频的带货数据？（→ 归纳模式时问，用于对照）

## 三、记录表（小二自己填；每段一组三行）

| 时间段 | 任务 | 📷 事实（画面/口播原文） | 💬 解释（我判断它在干什么） | ❓ 假设（待验证） |
|---|---|---|---|---|
| 0-3s | 停留 | 例：第2秒口播"别再买XX了" | 例：否定式痛点钩子 | 例：提升3秒留存→待验证 |
| 3-15s | 承接 | | 痛点展开+产品首现秒数 | |
| 中段 | 信任 | | 证明方式：演示/检测/销量/证言 | |
| 尾部 | 转化 | | 行动号召+价格出现时机 | |

钩子类型速查：疑问／痛点共鸣／悬念／反转／价格锚点／场景冲突

## 四、校准规则（资深小二的脑子）

**四段任务对照表**（AI按此查漏段、纠错判）：

| 段 | 任务 | 记录里该有什么 | 常见漏记/错记 |
|---|---|---|---|
| 0-3s | 停留 | 钩子原文+类型判断 | 只写"开头很抓人"——没记原文=没记录 |
| 3-15s | 承接 | 痛点展开方式+卖点首现秒数 | 忘记记"卖点第几秒出现"——这是关键数 |
| 中段 | 信任 | 证明方式（演示/检测/销量/证言） | 把"画面精致"当信任证据——那是制作不是证明 |
| 尾部 | 转化 | 行动号召原文+价格出现时机 | 漏记价格时机——它决定促单结构 |

**校准三抓**：
1. **感受词当事实**："氛围感强""节奏快"→要求改成画面/口播原文
2. **猜测当结论**：解释栏的话被写进结论→退回假设栏
3. **单条当规律**：只有一条记录支撑的"规律"→标"仅此条可见，暂不能下结论"

**红线**：AI只基于提交的记录校准；指出问题必须引用原句；**不虚构任何画面内容**。

## 五、报告格式（对内版＋商家版）

**对内版**：① 记录质量校准（原句→问题→改法）② 四段任务小结（钩子类型/卖点首现秒数/信任手段/转化机制）③ 可带走的2个做法+2个"暂不能下结论"的点
**商家版**：三句话——这条视频赢在哪一秒/哪个做法能搬到你家/搬完看什么数据

## 六、完整样例（全文虚构）

**【输入】**：Q1答：对标学习（家居收纳带货）；Q2答：默认。小二记录（节选）：0-3s 事实="第2秒口播'宿舍再小也能住出两人间的感觉'"、解释="场景冲突钩子"、假设="提升3秒留存→待验证"；中段 事实="（空）"、解释="画面很精致，感觉挺信任的"。

**【输出·对内版】**（节选）：
> **① 校准**：原句"画面很精致，感觉挺信任的"→问题：这是感受不是证据，且中段"事实"列为空→改法："第18-21秒：手持检测报告特写3秒，口播'甲醛实测0.02'"（若视频里没有具体证明动作，则该视频的信任段缺失，本身就是发现）。
> **② 四段小结**：钩子=场景冲突（空间反差）；卖点首现=第9秒；信任=检测报告特写（补记后）；转化=价格第23秒出现，先比价后报价。
> **③ 可带走**：①"空间反差"钩子适合小户型人群 ②检测报告做信任锤。"暂不能下结论"：①该钩子对3秒留存的提升 ②价格后置是否提升转化（均需Day17对照组验证或多条拆解）。

**【输出·商家版】**（三句）：
> 这条视频赢在第2秒——"宿舍住出两人间的感觉"一句话让小户型的人停下来了；您家能把这句换成"出租屋住出样板间的感觉"，产品第9秒再出场；拍完先看3秒完的数据，别急着全量投。

**样例演示了什么**：感受词被退回并给了改法；"暂不能下结论"与"可带走"严格分开；商家版落到一句可抄的钩子。

## 七、质检清单（AI输出前自检）

1. 有没有"看到"记录里没有的画面？（有=删）2. 每条校准引用了原句？3. "待验证"单独成列？4. 区分了"单条可见"和"多条一致"？5. 商家版给了可抄的一句？

## 八、常见坑（小二侧）

1. **让AI直接"分析这条视频"**——它没看过，必编；这是本工具第一红线
2. **事实栏写形容词**——"精致""大气"全退回，只收画面和原话
3. **拆一条就下结论**——单条只能出"待验证假设"
4. **漏记卖点首现秒数**——这是后续共性验证的关键字段
5. **只拆高表现组**——对照组也要拆，差异才看得见

## 九、验收三测（第一次用，先考AI）

1. 只发"这条视频氛围感很强"——合格反应是**要求补充画面/口播原文**，拒绝对"氛围感"做任何分析
2. 故意在记录里写一个AI没被告知的细节（如"第40秒出现logo"）后再问它第45秒是什么——合格答案是"记录里没有，我不知道"
3. 让它总结规律——合格输出应区分"本条可见"与"需多条验证"

## 十、AI纪律

没看过视频，不凭空分析；只做校准与归纳；事实/解释/假设三权分立；引用原句。
