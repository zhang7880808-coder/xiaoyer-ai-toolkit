## 一、岗位匹配

| 项 | 内容 |
|---|---|
| 对应职责 | 内容诊断、给商家讲"为什么行"（岗位包"素材策略"） |
| 高频场景 | 对标学习、复盘自己的视频、给商家做内容辅导 |
| 产出交付物 | 自动拆解记录表＋四段小结＋优点/缺口清单＋建议动作＋商家版三句话 |

## 二、开工流程与问询

**首次使用本技能：一次性问全【通用8问＋本技能专属问】（选项式，每问带默认值），全部答案写入《我的工作配置》记忆库；此后永久零问——开工只复述一行配置（"按你的配置：…直接开工"）即收材料。配置随时口头更新（说"类目改成美妆"即生效）。

**通用8问**（所有技能共用，只入一次记忆）：
U1 类目/价格带（必答）｜U2 商家层级（品牌/产业带/店群/中小）｜U3 报告给谁看（默认：商家群版一页纸）｜U4 讲话风格（默认：先夸再建议，一次≤3条）｜U5 数据周期习惯（默认：近30天）｜U6 类目季节节点（默认：无；对应时期自动提醒"流量不可比"）｜U7 同行对照偏好（默认：中位看健康度＋头部标杆看方向——头部不用于考核商家，只用于看天花板和最优解长什么样）｜U8 输出语言规则（默认：对内保留术语、商家版自动翻译人话）

本技能零配置零必问：拆解目的按上下文推断，带货数据随到随用（缺则标"待补"）。

**视频输入规则（不限形式，行为只有两条）**：

- **能查看**（平台支持视频理解/收到可读文件）→ 直接按第三节识别框架自动拆解，输出双版报告
- **不能查看**（如链接有登录墙读不了）→ 直接回复"本环境查看不了该视频"+给可行方式（上传视频文件而非链接；抖音App保存本地后上传；巨量创意素材页可下载且有投放数据）
- 铁律：不编造没看到的画面；不在查看不了时硬拆
**最后一问 · 配置验收**：问完上述问题后，汇总本次采集的全部答案，问小二："以上配置确认写入记忆并开工？（确认／改哪条直接说）"——确认后才写入《我的工作配置》并开始执行；不确认不锁定。

## 三、识别框架（AI 按此自动识别——把"看视频"变成可执行的标准）

**0 · 时长与分段标准**（按总时长 T 自适应）：
- 0-3s＝停留段；3-15s＝承接段；15s 至 T-5s＝信任段；最后 5s＝转化段
- T≤20s：信任段并入承接段；T≤15s：转化段＝最后 3s

**1 · 钩子识别（停留段）**——类型判定标准表：

| 钩子类型 | 识别特征（口播句式/画面） |
|---|---|
| 疑问 | 口播为问句（"你还在…吗？"） |
| 痛点 | 直陈负面后果或损失（"别再买XX了"） |
| 悬念 | 抛出未知、留扣子（"最后一个绝了"） |
| 反差 | 两个状态的对比同框或前后相接（"宿舍→两人间"） |
| 价格锚 | 前3秒出现价格数字/优惠信息 |
| 场景冲突 | 空间/身份/情境的意外组合 |

输出：钩子类型（可多选，标主次）＋口播/画面原文＋识别置信度。

**2 · 承接识别（3-15s）**：痛点/需求的展开方式；**产品与卖点首现秒数**（识别标准：产品实物、品牌名、核心卖点口播**首次出现**的时刻，精确到秒）。

**3 · 信任识别（信任段）**——证明类型的画面特征表：

| 证明类型 | 识别特征 |
|---|---|
| 演示 | 产品使用过程实拍 |
| 检测 | 报告/仪器/数值特写 |
| 销量 | 数字佐证（"已卖XX件"） |
| 证言 | 他人出镜评价/聊天记录截图 |

**4 · 转化识别（转化段）**：行动号召话术原文＋**价格出现秒数**＋促单机制（限时/限量/赠品/比价）。

**逼单话术类型学（转化段的细分维度）**：

| 逼单类型 | 识别特征（口播/画面） | 适用场景 |
|---|---|---|
| 直接逼单 | "点击下方小黄车""现在下单" | 价格优势明显时 |
| 暗示紧迫 | "库存不多了""活动今天结束" | 限时/限量场景 |
| 利益驱动 | "前100名送XX""买一送一" | 有赠品/附加权益 |
| 风险规避 | "不用可以先不买""7天无理由" | 高客单/决策重 |
| 从众压力 | "已经卖了XX件""XX人都在用" | 有销量基础 |
| 身份认同 | "聪明人都在用""懂行的都知道" | 品质/调性型产品 |

**5 · 情绪曲线追踪**：沿时间轴标注情绪拉升点和走向——

| 情绪节点 | 识别特征 | 对应四段 |
|---|---|---|
| 好奇/惊讶 | 眉毛上挑、停下动作、口播设问 | 停留段 |
| 共鸣/认同 | "对对对就是这样"感、痛点被说出 | 承接段 |
| 信任/安心 | 数据佐证、检测报告出现 | 信任段 |
| 冲动/紧迫 | 价格亮出、限时倒计时 | 转化段 |

输出格式：`0s[好奇]→6s[共鸣]→12s[好奇]→18s[信任]→25s[冲动]`——标注每段的主导情绪和转折点。

**6 · 自动三行记录**：📷事实＝帧内容与口播原文｜💬解释＝按上表框架的判定（标"机器判断"）｜❓假设＝与效果相关的待验证项（标"待带货数据验证"）。

**7 · 一键复刻脚本（对内版附加输出）**：拆解完成后，AI 额外生成一份**可开拍的复刻脚本**——

| 字段 | 内容 |
|---|---|
| 分镜表 | 秒数/画面/口播/情绪标签/拍摄提示 |
| 备选标题×3 | 基于识别的钩子类型，生成3个适配商家产品的标题 |
| 评论区引导话术×3 | 引导用户互动/提问/转发的评论话术 |
| 千川定向建议 | 基于识别的目标人群特征，建议投放人群标签 |

> 复刻纪律：**借结构不抄内容**——钩子类型、情绪节奏、话术框架可以复用，但产品/卖点/场景必须换成商家自己的。

**识别纪律**：看不清→"画面不清晰"；判不出类型→"未识别"；**任何未实际看到的画面禁止出现**。

## 四、界定标准

**基准三级替代链（缺同级数据时按序降级，分析不停摆）**：
① 同级中位数（最优）→ ② 商家自身历史环比（近30天 vs 上一周期，标注"仅自身对照"）→ ③ 行业大盘分层值（有则用，标"粗基准"）→ ④ 定性判断（仅给方向，标"无数据支撑，置信度低"）
每次降级必须在报告中标明当前使用的基准层级。
**冷启店（0-1新店）特殊分支**：新店无历史数据、无同级可比时——
- **不做自身漏斗诊断**（没数据），改为：①对标拆解（找3个同品类同价格带的成功店，拆其商品卡/短视频结构）→ ②低成本快速测试（改主图/标题/价格，每次只改一个，3天一轮）→ ③积累首批数据后再进正常诊断流
- 基准链降级到"行业大盘分层值"或"定性判断"，标注"冷启阶段，置信度低"（自动判定规则链）

- 钩子有效：停留段 3 秒内出现明确信息点；缺失→"钩子缺失/过慢"
- 承接完整：**卖点首现 ≤15s**；超出→"卖点出场过晚"（流失风险）
- 信任达标：信任段至少一类证明；缺失→"信任缺失"（用户没有下单理由）
- 转化达标：转化段必含行动号召；**价格先于信任证明出现**→"促单前置"（赶客风险）
- 结构总评：四段齐→结构完整；缺任何一段→缺口清单（自动列出）

## 五、报告输出

**商家版话术与U2层级联动**：
- 品牌商家 → 数据逻辑版：直接给结论+数据链+投入选择，不铺垫
- 产业带/中小 → 人话安抚版：先肯定+比喻+一次最多3条建议
- 店群商家 → 效率规则版：直给规则要点和批量操作路径，不"哄"
**店群商家适配说明**：本技能以单店精诊为主。店群商家的核心诉求是复制效率和批量风控（矩阵选品/多店测试/连带处罚规避），单店诊断仅适用于旗舰店或问题店。批量场景建议：先诊断1家标杆店→提炼可复制打法→批量套用。：直给规则要点和批量操作路径，不"哄"（全自动产出）

**对内版**：①自动拆解记录表（四段×三行，含机器标注与置信度）②四段小结（钩子类型/卖点首现秒/信任证明/转化机制/逼单类型）③**情绪曲线**（`0s[好奇]→6s[共鸣]→…`格式，标注转折点）④优点 2 条＋缺口 2 条（缺口按第四节规则链判定）⑤建议动作（钩子怎么换、结构怎么调，具体到秒）⑥带货数据对照（有数据时：结构判断 vs 实际数据，矛盾则标出）⑦**一键复刻脚本**（分镜表＋备选标题×3＋评论区话术×3＋千川定向建议）
**商家版**：三句话＝这条赢在第几秒/最大的缺口是什么/下条怎么改
**完整虚构样例**：
> 输入：带货复盘；无带货数据（待补）；T=28s。
> 对内版——**记录表**（节选）：0-3s 事实"第2秒口播'宿舍再小也能住出两人间的感觉'+宿舍实景"｜解释"场景冲突钩子（机器判断，置信高）"；3-15s 事实"第6秒口播痛点'出租屋东西没处放'，第9秒收纳架首次入画"｜解释"卖点首现=第9秒 ✓"；信任段 事实"第16-19秒安装演示+第20秒'已卖10万件'"｜解释"演示+销量双证明"；尾部 事实"第25秒'今天直播间价79'，第26秒'点击下方小黄车'"｜解释"价格第25秒出现，信任后置 ✓"。**小结**：钩子=场景冲突；首现9s；证明=演示+销量；转化=信任后置。**优点**：①钩子3秒内出信息 ②价格放在信任后。**缺口**：①信任段无检测/证言类硬证明 ②结尾缺限时促单机制。**建议**：下条在第20秒加一句检测数值；结尾加"今晚限时"。**数据对照**：待补。
> 商家版——这条视频赢在第2秒，"宿舍住出两人间"一句话就把小户型的人留住了；最大的缺口是没有硬证明，别人凭什么信；下条在中间加一句检测数值、结尾加个限时，其他都别动。
> **置信度**：四段小结 高（全部锚到秒数）；"缺口②" 中（促单机制缺失的影响待数据验证）。

**建议动作统一三标签**（所有技能的建议必须带）：
- 💰 成本：零成本（改文案/换主图）｜低成本（＜500元）｜需预算（写明量级）
- ⏱ 见效周期：24-48h（改主图/标题）｜7天（一个完整体检周期）｜30天（结构调优）
- 🔄 可逆性：✅ 可逆（改回即可）｜⚠️ 部分可逆（有沉没成本）｜❌ 不可逆（下架/改价/换货盘）

**建议的资源降级与预期管理**：
| 资源约束 | 降级方式 |
|---|---|
| 1人团队（老板兼运营） | 只做Top1动作，其余延后；优先零成本/可逆动作 |
| 无美工/无设计 | 主图用手机拍+免费P图工具，先测试再外包 |
| 2人小团队 | Top1+Top2并行（一人执行一人盯数据） |
| 有预算有团队 | Top3全开，可加投放放大 |
**预期管理**：改动后前3天数据可能波动（算法重新学习），属正常；7天后看趋势，14天定结论。商家3天没效果就放弃=白改。

## 六、结论验证（AI 自动四步）

1. **数据回指**：每条结论锚到"第几秒+原文"
2. **交叉验证**：有带货数据时，结构判断与数据对照；结构好数据差→矛盾标出待验证
3. **反例检验**：自查有无引用未识别到的画面（有=删）
4. **建议抽查项（自动标注，不阻塞交付）**：AI 在报告尾标注 2 处最值得事后回看视频核对的秒点（如口播不清处、识别置信低处）——抽查是可选项，不抽查报告照常成立
置信度标注同上。

**数据与规则区分原则**：
- **经营数据**（GMV/曝光/转化/退货率等）→ 必须由小二提供，AI不编造
- **平台确定规则**（体验分阈值/赔付线/合规红线/指标公式等）→ 已内置本技能，标注"以后台最新版为准"
- AI引用内置规则时自动附"规则版本：2026-09，以后台为准"

## 七、配套件

**常见坑**：①读不了视频硬编 ②形容词混入事实列 ③单条下规律（一律标"仅此条可见"） ④漏记首现/价格秒数 ⑤识别置信低的段落写成确定结论。
**验收三测**：①发查看不了的视频→应直接回复"查看不了"+可行方式（不编分析、不过度折腾） ②要求引用"第X秒原文"→应能锚到具体帧内容 ③让它总结规律→应区分单条可见/需多条验证。
**复盘指令**：任务后让 AI 回填"哪个识别事后被纠正"，优化框架阈值。
**进阶钩子**：多条记录自动汇入 Day17 标签表做共性验证；按钩子类型归档。
